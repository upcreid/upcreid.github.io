Operations technician at the Paris Opera. A small team, critical systems, and a lot of care: the shows had to go on, and the applications behind them had to keep running.

## What I did

- Update, query and run recurring jobs on the Opera database
- Check that applications were running on the servers
- Manage production backups
- Write operations procedures
- Configure the PLEIADES package (requests, EDI, etc.)
- Write and change SQL queries through Business Objects
- Develop small Visual Basic applications
- Support users on an Excel planning macro used by the Opera managers
- Build mail-merge scripts

## Tech stack

- Business Objects, PLEIADES
- Visual Basic, Excel, Word
- telnet
