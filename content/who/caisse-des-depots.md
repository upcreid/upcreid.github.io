A data migration project for a public financial institution: take decades of data out of legacy systems and put it into a clean Oracle database, without losing a single row. Half engineer, half translator between the business and the systems.

## What I did

### Solutions analyst

- Shell scripts to recover legacy data (MVS, DB2, Oracle, Sybase, XML)
- Clean, enrich and reshape the data before loading
- Load it into Oracle (reference data, derivations, banking flows)
- Reconcile counts between source and target
- Update secure file transfers (CFT)
- Batch scripting to format data automatically (WinSCP, Excel)
- Orchestrate the jobs with Control-M
- Write and tune SQL queries
- Package everything in a dedicated SVN repository (KSH, SQL, ENV)
- Train the team on SVN and continuous delivery habits
- Build shell functions used across the CDC infrastructure
- Validate deliverables (technical documents, product)

### Business analyst

- Run workshops with business teams to define migration rules from source analysis
- Analyse the data to migrate
- Define the migration sequence and rules
- Assist the business teams during acceptance testing
- Define flow matrices and configure the transfer tools
- Write documentation and communicate in French and English

## Tech stack

- CFT (SOPRA)
- Unix, KSH, Windows Server 2003, VBS, Citrix, Cisco
- Oracle, Sybase, MVS, DB2
- SVN, Quality Center, JIRA, Control-M
