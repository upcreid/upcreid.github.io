Embedded software technician on engine control units. I wrote and tested the engine functions that lived inside the Motronic ECU — code that had to be right long before it ever reached a car.

## What I did

- Analyse and develop engine functions in C/C++ for Motronic
- Review code for performance
- Write unit and integration tests
- Freeze versions before series production
- Validate on test benches and on vehicles
- Document each function
- Write the test methodology

## Tech stack

- C, C++, ASM
- CodeWright
- Messplatz Labcar (bench lab)
- in-house tools and software
