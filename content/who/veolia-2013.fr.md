Consultant technique sur le projet Next (Wallstreet Systems, SwiftNet, Reuters). J'avais la charge des environnements de production et j'ai accompagné une montée de version majeure, de l'intégration jusqu'à la mise en production, en gardant le support et l'exploitation dans la boucle.

## Ce que j'y faisais

### Intégration et environnements

- Intégrer chaque version livrée par l'éditeur sur les plateformes d'intégration
- Mettre en place le monitoring pour voir comment chaque version se comporte
- Scripts shell : contrôle de File System, purge de logs, backups
- Rafraîchissement quotidien de la base pour le datawarehouse (RMAN, SQL, shell)
- Conduire la mise en place des transferts de flux avec les autres entités Veolia (Dalkia, transport, eau…)
- Construire une base d'analyse à partir des logs applicatifs
- Requêtes SQL de reporting et de contrôle
- Gérer la configuration SVN sur INT / REC / VAL / PROD avec les équipes de production VEIT
- Créer des branches SVN pour suivre chaque environnement
- Analyser et mettre en place les flux bancaires
- Traduire les besoins utilisateurs en spécifications techniques pour l'éditeur
- Rédiger les spécifications fonctionnelles et les documents d'exploitation

### TMA / Support niveaux 2 et 3

- Former le support niveaux 2 et 3 sur la nouvelle version
- Rédiger la procédure d'installation
- Packager les livrables pour la production
- Optimiser la production (analyse SQL, retours éditeur, config Oracle et serveur)
- Mettre en place les alertes et les notifications par email
- Communiquer et escalader sur les incidents
- Gérer les plans de secours et de reprise d'activité
- Adopter les pratiques ITIL (gestion du changement)

## Environnement technique

- HP-UX, Windows Server 2003, Citrix, IIS
- Oracle 10g, SQL, PL/SQL, SQL Developer
- Weblogic, Apache, WSS Suite, activeMQ
- Java, shell, Python, Perl
- SWIFT Alliance, esiadapter, RMDS, CFT, FTP, Samba
- SVN, Centreon, ServiceNow
