Technical consultant on the Next treasury project (Wallstreet Systems, SwiftNet, Reuters). I owned the production environments and helped carry a major version upgrade all the way from integration to go-live, while keeping support and operations in the loop.

## What I did

### Integration and environments

- Integrate every vendor release across the integration platforms
- Set up monitoring to see how each delivered version behaves
- Shell scripts for filesystem checks, log purging and backups
- Daily database refresh for the data warehouse (RMAN, SQL, shell)
- Lead the setup of file transfers with other Veolia entities (Dalkia, transport, water…)
- Build an analysis database from application logs
- SQL reporting and control queries
- Manage SVN configuration across INT / REC / VAL / PROD with the VEIT production teams
- Create SVN branches to track each environment
- Analyse and set up banking flows
- Translate user needs into technical specs for the vendor
- Write functional specs and operations runbooks

### TMA / L2-L3 support

- Train L2 and L3 support on the new version
- Write the installation procedure
- Package deliverables for production
- Optimise production (SQL analysis, vendor feedback, Oracle and server config)
- Set up alerting and email notifications
- Communicate and escalate on incidents
- Manage disaster recovery plans
- Adopt ITIL practices (change management)
