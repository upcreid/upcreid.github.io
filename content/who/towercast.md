My first internship: building a small Windows application to read GPS data. It taught me a lot about serial links, data frames, and keeping an interface readable.

## What I did

- Understand how the GPS system works
- Receive NMEA data from a GARMIN GPS over an RS232 serial link
- Parse and transform the NMEA frames
- Program the reception in Delphi
- Build a GUI to make the receiver output readable

## Tech stack

- Delphi, Visual Studio
- RS232 serial link
- GPS NMEA data
- GPS technology
