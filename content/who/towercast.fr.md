Mon premier stage : une petite application Windows pour lire des données GPS. Ça m'a beaucoup appris sur les liaisons série, les trames de données, et l'art de garder une interface lisible.

## Ce que j'y faisais

- Comprendre le fonctionnement du système GPS
- Recevoir les données NMEA d'un GPS GARMIN via une liaison série RS232
- Analyser et transformer les trames NMEA
- Programmer la réception en Delphi
- Créer une interface graphique pour rendre les données du récepteur lisibles

## Environnement technique

- Delphi, Visual Studio
- Liaison série RS232
- Données GPS NMEA
- Technologie GPS
